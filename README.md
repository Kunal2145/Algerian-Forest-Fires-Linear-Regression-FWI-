# Algerian Forest Fires — Lasso, Ridge & ElasticNet Regression

This project analyzes the **Algerian Forest Fires dataset** and builds regression models to predict the **Fire Weather Index (FWI)** from weather and fire-related features, comparing Linear Regression against three regularized variants: **Lasso, Ridge, and ElasticNet**.

## Dataset

The dataset contains 244 instances covering two regions of Algeria:

- **Bejaia** region (northeast)
- **Sidi Bel-abbes** region (northwest)

There are 122 instances per region, collected between June and September 2012.

**Features include:**

| Feature | Description |
|---|---|
| Date | Day, month, year of observation |
| Temperature | Noon temperature (°C) |
| RH | Relative Humidity (%) |
| Ws | Wind speed (km/h) |
| Rain | Total rainfall (mm) |
| FFMC, DMC, DC | Fire Weather Index sub-components (fuel moisture codes) |
| ISI | Initial Spread Index |
| BUI | Buildup Index |
| **FWI** | Fire Weather Index — target variable |
| Classes | `fire` / `not fire` label |

## Project Workflow

### 1. Data Cleaning

- Handled missing values and malformed rows
- Split the combined dataset into two regions using a new `Region` column
- Fixed column name whitespace and corrected data types
- Exported a cleaned CSV (`Algerian_forest_fire_cleaned.csv`)

### 2. Exploratory Data Analysis (EDA)

- Feature distribution histograms
- Class balance pie chart (`fire` vs. `not fire`)
- Correlation heatmap across features
- Boxplot inspection of the FWI target
- Monthly fire-count analysis per region

### 3. Feature Engineering

- Dropped `day`, `month`, and `year` for modeling
- Encoded `Classes` as binary (`0 = not fire`, `1 = fire`)
- Removed highly correlated features (correlation threshold > 0.85) to reduce multicollinearity
- Scaled features using `StandardScaler`

### 4. Model Training

- Train/test split: **75% / 25%**
- Trained and evaluated four regression models:
  - Linear Regression (baseline)
  - **Lasso Regression**
  - **Ridge Regression**
  - **ElasticNet Regression**
- Evaluated models using:
  - **Mean Absolute Error (MAE)**
  - **R² Score**

## Results

| Model | MAE | R² Score |
|---|---:|---:|
| Lasso | 1.133 | 0.949 |
| Ridge | **0.564** | **0.984** |
| ElasticNet | 1.882 | 0.875 |

**Ridge Regression** delivered the best performance, achieving the highest R² score and the lowest MAE on this dataset and hyperparameter setup.

## Key Takeaways

- **Ridge Regression** reduces overfitting by shrinking coefficients without eliminating them, making it useful when most features carry some predictive signal.
- **Lasso Regression** performs implicit feature selection by shrinking less important feature coefficients to exactly zero.
- **ElasticNet Regression** combines both L1 and L2 regularization, balancing feature selection with coefficient shrinkage.
- In this experiment, **Ridge Regression achieved the best overall performance** with an R² score of **0.984** and MAE of **0.564**.
